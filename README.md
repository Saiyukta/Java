# Java Learning & Practice

This repository contains my Java learning journey, including practical exercises, coding examples, and implementations of core Java concepts.

The objective is to strengthen my understanding of Java fundamentals through hands-on practice.

## Topics Covered

### 1. Functional Interfaces
- Understanding functional interfaces
- Built-in functional interfaces
- Predicate, Function, Consumer and Supplier
- Creating custom functional interfaces

### 2. Generics
- Generic classes and methods
- Type parameters
- Bounded type parameters
- Practical implementations of generics

### 3. Lambda Expressions
- Lambda expression syntax
- Functional interface implementation using lambdas
- Refactoring anonymous classes using lambdas
- Practical examples

### 4. Streams API
- Stream creation and pipelines
- Filter, Map, FlatMap and Sorted
- Distinct, Limit and other intermediate operations
- Reduce and Collect
- Practical data-processing exercises

### 5. Method References
- Static method references
- Instance method references
- Constructor references
- Simplifying lambda expressions

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Saiyukta/Java.git
   ```

2. Open the project in IntelliJ IDEA or another Java IDE.

3. Make sure a compatible JDK is configured.

4. Navigate to the relevant topic folder under `src`.

5. Open an individual exercise and run its `main()` method, where available.
